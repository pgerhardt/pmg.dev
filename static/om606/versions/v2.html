Historical checkpoint

OM606 Powertrain Lab V2

Specification phase — no runnable V2 application was produced.
V2 converted the V1 curve generator into a formal engineering feature specification. V3 was the first implementation of that specification.

Primary model changes specified

  • Replace arbitrary torque adders with an air/fuel/limit model.
  • Compute combustion torque as min(fuel-limited, air-limited, mechanical, thermal).
  • Treat turbocharger, supercharger, and electric compressor as airflow devices.
  • Calculate supercharger parasitic power and subtract crankshaft torque loss.
  • Give the P2 motor separate torque, power, battery, and thermal limits.
  • Expose unrestricted torque and every limiting constraint instead of silently clipping.
  • Separate steady-state dyno behavior from transient throttle, launch, and shift simulations.

Product features specified

  • Named presets and baseline overlays.
  • Component, airflow, limiter, and vehicle-level graphs.
  • Wheel torque, gearing, traction, and acceleration calculations.
  • Configuration import/export, local persistence, CSV, and PNG export.
  • Click-an-RPM calculation explanations and explicit model assumptions.
  • Fully offline packaging with no CDN dependency.

Historical role

V2 is retained here so the version selector accurately represents the project history. It is documentation, not a fabricated executable release.
